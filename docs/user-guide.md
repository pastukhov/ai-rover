# Руководство пользователя AI Rover

Это руководство для Алёны и взрослого помощника. В нём описано, как пользоваться ровером, как подключать его к Wi-Fi, как включать LLM-чат и что делать, если что-то пошло не так.

## Что умеет ровер

AI Rover построен на базе **M5StickC Plus** и **RoverC Pro**.

Он умеет:

- ездить вперёд и назад;
- смещаться влево и вправо благодаря колёсам Mecanum;
- поворачиваться на месте;
- открывать и закрывать захват;
- показывать состояние на экране;
- поднимать веб-интерфейс управления;
- хранить настройки Wi-Fi и LLM во внутренней памяти;
- создавать собственную Wi-Fi-точку доступа, если домашний Wi-Fi не настроен или недоступен.

Камера и vision-инструменты в текущей версии прошивки отключены.

## Включение

1. Поставьте ровера на безопасную поверхность.
2. Включите питание базы RoverC Pro.
3. Дождитесь загрузки M5StickC Plus.
4. Посмотрите на экран:
   - **AP MODE** - ровер создал свою Wi-Fi-сеть;
   - **WiFi OK** - ровер подключился к сохранённой Wi-Fi-сети;
   - **OFFLINE** - сеть не готова или идёт переключение.

На экране также отображается IP-адрес. Он нужен, чтобы открыть веб-интерфейс.

## Режимы подключения

### Режим точки доступа

Если ровер не может подключиться к Wi-Fi, он создаёт открытую точку доступа:

```text
AI-Rover-XXXX
```

`XXXX` - часть MAC-адреса устройства, поэтому имя может отличаться.

Пароля у точки доступа нет. Это сделано специально, чтобы подарок можно было запустить без подготовки и без знания домашних настроек.

После подключения к этой сети откройте в браузере IP-адрес, показанный на экране. Обычно это:

```text
http://192.168.4.1/
```

Телефон может предупредить, что у сети нет доступа к интернету. Это нормально: сеть нужна для связи с ровером.

### Режим клиента домашнего Wi-Fi

Когда в веб-интерфейсе сохранены SSID и пароль домашней сети, ровер пытается подключиться к ней при запуске.

Если подключение успешно, на экране появляется **WiFi OK** и IP-адрес в домашней сети. Откройте:

```text
http://<IP-на-экране>/
```

Также может работать mDNS-адрес:

```text
http://ai-rover.local/
```

mDNS зависит от операционной системы и настроек сети. IP-адрес на экране надёжнее.

## Веб-интерфейс

Веб-интерфейс находится на главной странице ровера:

```text
http://<IP-ровера>/
```

На одной странице находятся:

- кнопки управления движением;
- кнопки управления захватом;
- настройки Wi-Fi;
- настройки подключения к LLM;
- кнопка сброса настроек;
- чат, если LLM уже настроен.

### Управление движением

Основные команды:

| Кнопка | Действие |
|---|---|
| Forward | Вперёд |
| Back | Назад |
| Left | Сдвиг влево |
| Right | Сдвиг вправо |
| Turn Left | Поворот влево |
| Turn Right | Поворот вправо |
| STOP | Немедленная остановка |

Кнопка **STOP** - главная кнопка безопасности в веб-интерфейсе.

### Управление захватом

| Кнопка | Действие |
|---|---|
| Grip Open | Открыть захват |
| Grip Close | Закрыть захват |

Захват рассчитан на лёгкие предметы: кубики, небольшие детали конструктора, бумажные мишени.

## Настройка Wi-Fi

В блоке настроек есть выпадающий список Wi-Fi-сетей.

1. Нажмите **Rescan**.
2. Дождитесь списка сетей.
3. Выберите нужную сеть.
4. Введите пароль.
5. Нажмите **Save settings**.
6. Подождите, пока ровер применит настройки.

Список сетей дедуплицируется по имени: если рядом несколько точек доступа с одинаковым SSID, ровер показывает одну запись с самым сильным сигналом.

Если пароль оставить пустым при сохранении, прошивка воспринимает это как пустой пароль. Для домашней сети обычно нужно ввести пароль явно.

## Настройка LLM

LLM-чат нужен, чтобы отправлять роверу текстовые команды через модель, совместимую с OpenAI API.

Поля настройки:

| Поле | Назначение |
|---|---|
| LLM endpoint | Адрес API endpoint. Если оставить пустым, используется значение по умолчанию клиента |
| LLM API key | API-ключ |
| LLM model | Имя модели, по умолчанию `openai/gpt-4o-mini` |

Пока API key не сохранён, блок чата не отображается. Это сделано, чтобы не показывать неработающий чат при первом запуске.

После сохранения LLM-настроек чат появляется на странице. Через него можно просить ровера выполнить простые действия, например:

```text
проедь немного вперед
```

или:

```text
открой захват
```

LLM-команды не заменяют правила безопасности. Ровер всё равно должен стоять на безопасной поверхности, а **STOP** должен быть под рукой.

## Сброс настроек

Кнопка **Reset settings** очищает сохранённые настройки Wi-Fi и LLM.

После сброса ровер возвращается к базовому поведению:

1. Wi-Fi-сеть не задана.
2. LLM API key не задан.
3. Чат скрыт.
4. Если домашний Wi-Fi недоступен, ровер поднимает точку доступа `AI-Rover-XXXX`.

## Что означает экран

На экране отображаются несколько важных подсказок:

| Надпись | Значение |
|---|---|
| AP MODE | Ровер работает как Wi-Fi-точка доступа |
| WiFi OK | Ровер подключён к Wi-Fi |
| OFFLINE | Сеть не готова |
| GRIP OPEN | Захват открыт |
| GRIP SHUT | Захват закрыт |
| IP-адрес | Адрес веб-интерфейса |

Экран нужен как маленькая приборная панель. Если непонятно, куда подключаться, сначала смотрите на IP-адрес на экране.

## Кнопки на M5StickC Plus

| Кнопка | Назначение |
|---|---|
| BtnA | Запуск локального демо-сценария |
| BtnB | Аварийная остановка |

BtnB должен оставаться быстрым способом остановить движение, даже если веб-страница или LLM заняты.

## Идеи экспериментов

### Маршрут по комнате

Сделайте на полу старт и финиш из бумажного скотча. Нужно доехать до финиша, не задев препятствия.

Что можно изучить:

- почему робот едет чуть иначе на ковре и на столе;
- как влияет заряд батареи;
- как точнее поворачивать.

### Движение по квадрату

Попробуйте сделать квадрат:

1. Вперёд.
2. Поворот направо.
3. Вперёд.
4. Поворот направо.
5. Повторить до возвращения к старту.

После этого измерьте ошибку: насколько ровер не попал в начальную точку.

### Захват предмета

Поставьте лёгкий предмет перед ровером. Нужно подъехать, закрыть захват, отъехать и отпустить предмет в другой зоне.

Что можно обсудить:

- почему трудно попасть захватом точно;
- как выбирать скорость;
- почему роботу полезны датчики.

### Сравнение поверхностей

Проверьте одинаковую команду движения на разных поверхностях:

- стол;
- пол;
- коврик;
- лист бумаги.

Запишите расстояние после одинакового нажатия. Это уже маленький научный эксперимент.

## Если что-то не работает

### Не видно Wi-Fi-сеть ровера

1. Перезагрузите ровера.
2. Подождите 20-30 секунд.
3. Проверьте экран: должна появиться надпись **AP MODE**.
4. Ищите сеть вида `AI-Rover-XXXX`.

### Веб-страница не открывается

1. Проверьте, что телефон или компьютер подключён к сети ровера.
2. Проверьте IP на экране.
3. Откройте адрес с `http://`, не с `https://`.
4. Попробуйте обновить страницу.

### Список Wi-Fi пустой

1. Нажмите **Rescan** ещё раз.
2. Подождите несколько секунд.
3. Проверьте, что рядом действительно есть Wi-Fi-сети.
4. Если появляется ошибка scan failed, перезагрузите ровера.

### Ровер не едет

1. Нажмите **STOP**.
2. Проверьте выключатель питания RoverC Pro.
3. Проверьте заряд.
4. Перезагрузите питание.

### Чат не отображается

Это нормально, если LLM API key ещё не сохранён.

Откройте настройки, заполните endpoint, API key и model, затем сохраните. После этого чат должен появиться.

## Что можно улучшать дальше

Проект специально оставлен открытым для развития:

- добавить новые кнопки в веб-интерфейс;
- сделать готовые миссии;
- добавить датчики расстояния;
- добавить линии маршрута;
- написать новые команды для LLM;
- сделать журнал экспериментов.

Хороший следующий шаг для кружка робототехники - выбрать одну маленькую задачу, измерить результат, изменить программу и сравнить, стало ли лучше.
